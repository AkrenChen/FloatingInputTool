# 失焦附加模糊参数对照

用户报告失焦附加模糊变化不明显。首次观察：模拟失焦，界面 60%，磨砂覆盖 34%，附加模糊 29，底板 100%。底板完全遮住 Gaussian 输出，且低覆盖透入未模糊桌面，因此不能从该组合判断 Gaussian 无效。

用户随后将底板改为 49%。临时对照前保存：失焦模糊 29、磨砂覆盖 34%、底板 49%。将覆盖固定 100%、底板固定 0%，在独立动态网格窗口上比较附加模糊 0 / 64，出现明确视觉差异：0 保留系统基础磨砂和较清楚的色块轮廓，64 使色块与移动黑条大幅扩散。故本轮未发现该参数失效，无需更改原生 Gaussian 实现。

对照后已恢复失焦模糊 29、覆盖 34%、底板 49%，其余参数和模拟失焦模式保持。README 补充参数调节顺序；未重新构建或重启样机，正式版未变更。
