# 审查发现

- 主实现是 Tauri，AHK 是行为原型。README 和根目录计划仍残留早期 AHK 目标与过期阶段状态。
- SettingsApp 的 applyConfig 对所有字段及编辑草稿全量重置，保存一个设置或接收外部配置更新会覆盖其他未保存编辑。
- 设置默认宽度 560、最小 500，但快捷键行固定四列，窄屏媒体查询仅添加外层 padding，未处理行布局。
- 设置 Grid 声明三行，但反馈出现时增加为四个直接子节点，导致内容高度随反馈改变。
- 窗口动画逐步调用原生窗口 API 并 sleep；移动事件及草稿更新每次新建 OS 线程。窗口转换缺少统一串行化及取消机制。
- 恢复正常窗口函数未恢复 resizable=true；贴边时曾将其设为 false。
- 配置 setter 普遍先改共享内存再落盘，落盘失败后内存不回滚。
- 草稿 flush 克隆快照后释放锁再落盘，存在旧写入覆盖 clear 或新写入的并发风险。
- 以上均为静态分析；尚未复现用户现场故障。
