# Main-window composition migration

用户在样机最终参数确认后授权接入正式主窗口；实现阶段不操作桌面，代码/构建完成后再用 Computer Use 查看候选版。不安装、不提交，不修改用户笔记或草稿进行验证。

目标：保留现有捕获/保存/设置/贴边状态机，将主窗口从 Accent Acrylic 换为已验证的 Windows.UI.Composition。最终值：界面 1/0.34，磨砂覆盖 1/0.85，Gaussian 0/0，tint 0/0，shadow 5/0.24/2，radius 24。设置窗口保留原 Acrylic；初始化失败时主窗口使用可读的实色回退。

## 步骤
- [ ] 建立共享主题 JSON 与平台无关 surface model，复制经过样机验证的 effect/mask 渲染到生产模块。所有图形对象限制在 UI 线程；避免 HWND alpha 和可见白色投影源。
- [ ] 接入主窗口初始化、显示、焦点、DPI/resize、贴边模式和关闭生命周期；IPC 更新主题/预览，返回真实能力状态。设置窗口继续独立。
- [ ] 主窗口加阴影留白并保持原可见编辑尺寸；用内容矩形计算贴边判断和还原坐标；收起时隐藏合成层、留白归零。添加几何测试与内容边缘缩放命中区域。
- [ ] React/CSS 按原生状态淡化界面，透明底板交给原生；自定义主题调参页暴露对应参数、预览与导出。保证回退模式不继承低透明度。
- [ ] Rust tests/check/fmt、前端 tests/lint/build、候选 release 构建。完成后用 Computer Use 检查实际捕获窗、聚焦/失焦、设置、缩放和贴边；记录无法完成的桌面/IME/多机验证，不将参数回读冒充图像验收。

交付前对照用户原话：必须接入真实捕获窗和最终参数，不能只更新样机。用户占用电脑时实现阶段不进行 UI 自动化。
